# Praxivyn

### Engineer. Automate. Empower.

Praxivyn is a cloud-native Internal Developer Platform
designed to simplify application development,
infrastructure provisioning, secure delivery and
Kubernetes operations.

## Vision

Enable developers to provision, deploy and monitor
applications through a self-service developer portal.

## Core Capabilities

- Self-service application scaffolding
- Automated infrastructure provisioning
- CI/CD automation
- GitOps-based deployments
- Kubernetes security and governance
- Centralized observability
- Multi-cloud architecture

## Technology Stack

- Backstage
- Go
- Docker
- Kubernetes
- Kind
- GKE
- Terraform
- Helm
- GitHub Actions
- Flux CD
- Kyverno
- OpenTelemetry
- Prometheus
- Grafana
